`mend` applies the edits AI models write — unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON editor calls — to a tree of text files, matching the lines each edit names at three tiers and writing every change or none. Single-file Node 22 CLI, no dependencies; 1000/1000 on the public practice set.

## Run it

```sh
node main.ts [--format=auto|unified|search-replace|v4a|json] [--check] [--strict] [PATCH]
```
